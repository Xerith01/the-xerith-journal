# Quick launch checklist

- [ ] Replace the sample entry with your own first public post.
- [ ] Review the About page and brand details.
- [ ] Put the folder contents into a GitHub repository.
- [ ] Import that repository into Netlify with `npm run build` and `_site`.
- [ ] Configure a supported CMS authentication backend and restrict registration to your account.
- [ ] Test `/admin/` in a private browser window.
- [ ] Test a draft, a published post, a featured image, and mobile layout.
- [ ] Confirm no private notes or sensitive files are in the repository.
